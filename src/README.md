# Source Files

This folder is for editable design/source assets for the model.

In repos created from this template, add subfolders as needed for the tools you use (for example: Tinkercad exports/projects, Bambu Studio `.3mf` projects, Autodesk Fusion files, or other CAD sources).

## Purpose
- Keep the original, editable project files separate from published/exported files.
- Preserve your working design history and tool-specific assets.

## In derived repos
- Create tool-specific subfolders under this directory.
- Use clear folder names (for example, by app name or by part/component).
- Include notes or version context in each subfolder when helpful.
